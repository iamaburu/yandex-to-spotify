Подключения

Яндекс.Музыка
  1. Откройте страницу Яндекса, войдите и нажмите «Разрешить».
  2. Скопируйте из адресной строки весь адрес (он начинается с https://music.yandex.ru/#access_token=) и вставьте ниже. Лишнее программа отрежет сама.

Если адрес успел смениться: откройте инструменты разработчика (⌥⌘I, на Windows F12) → вкладка Network → включите «Preserve log» и повторите.

Spotify

Spotify разрешает программам ставить лайки только через бесплатное «приложение разработчика». Его создание занимает пару минут:

  1. Откройте developer.spotify.com/dashboard, войдите и нажмите Create app.
  2. App name и App description — любые, например yandex-to-spotify.
  3. Redirect URIs — вставьте ровно и нажмите Add.
  4. В «Which API/SDKs are you planning to use?» отметьте Web API, согласитесь с условиями и нажмите Save.
  5. Откройте Settings: там Client ID и (по кнопке View client secret) Client secret.
