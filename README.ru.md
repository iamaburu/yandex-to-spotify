# yandex-to-spotify

[English version](README.md)

**Перенесите лайки из Яндекс.Музыки в «Любимые треки» Spotify примерно за 15 минут.** Запуск двойным кликом, дальше пошаговый мастер проведёт по всем шагам. Программировать уметь не нужно.

- **Ничего не меняется без вашего согласия.** Надёжные совпадения лайкаются автоматически, а сомнительные (live-версии, ремиксы, другое написание) программа сначала покажет вам.
- **Умный поиск.** Программа понимает, что `Сплин` и `Splean` — один исполнитель, и сверяет длительность треков.
- **Сохраняет порядок.** Самые новые лайки из Яндекса окажутся сверху в Spotify.
- **Можно запускать повторно.** Уже добавленные треки пропускаются, прерванный перенос продолжается с того же места. Новые лайки можно перенести позже.
- **Отмена.** Одной командой убирается всё, что добавила программа.
- **Приватно.** Токены хранятся только на вашем компьютере, код открыт.

## Быстрый старт

1. [Скачайте последнюю версию](https://github.com/iamaburu/yandex-to-spotify/releases/latest) (**Source code (zip)**) и распакуйте архив.
2. Дважды кликните по **`start.command`** на macOS или **`start.bat`** на Windows. На Linux выполните `./start.sh`.
3. Следуйте подсказкам мастера. Он сам откроет нужные страницы и проверит всё, что вы вставите.

Нужен Python 3.9 или новее. На macOS, если его нет, мастер подскажет, как установить.
На Windows скачайте Python с [python.org](https://www.python.org/downloads/) и отметьте галочку **Add python.exe to PATH**.

**[📖 Подробная пошаговая инструкция и решение частых проблем →](docs/GUIDE.ru.md)**

## Что понадобится
- Аккаунт Яндекс.Музыки. Токен доступа мастер поможет получить в два клика.
- Аккаунт Spotify (Free или Premium) и бесплатное «приложение разработчика» Spotify. Мастер проведёт по его созданию, это займёт около двух минут.

## Для продвинутых

Каждый шаг можно запустить отдельной командой:
```sh
./start.command <команда>        # Windows: start.bat <команда>
```
| команда | что делает |
|---|---|
| *(без команды)* | пошаговый мастер |
| `setup` | ввести доступы к Яндексу и Spotify |
| `check` | проверить доступ к обоим сервисам |
| `export` | выгрузить лайки Яндекса в `data/yandex_likes.json` |
| `match` | найти треки в Spotify и записать `data/report.csv` (ничего не лайкает) |
| `review` | проверить сомнительные совпадения |
| `like [--dry-run]` | лайкнуть все треки со статусом `ok` |
| `undo [--dry-run]` | убрать всё, что добавила программа |

Файл `data/report.csv` можно править вручную: лайкаются строки со статусом `ok`, а статусы `check`, `skip` и `not_found` пропускаются.

## Ограничения и ответственность
- У Яндекс.Музыки нет публичного API. Программа использует неофициальную библиотеку [`yandex-music`](https://github.com/MarshalX/yandex-music-api) и OAuth-клиент официального приложения Яндекс.Музыки, поэтому может перестать работать, если Яндекс что-то изменит.
- Проект не связан с Яндексом и Spotify. Используйте на свой риск.
